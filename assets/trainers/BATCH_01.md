# Trainer batch: March, Arm Circles, Wall Push-Up

Created with the built-in image-generation tool using `squat-trainer-source.png` as the character/style reference. The image-generation skill guided reference use, per-asset generation, inspection and saving into this workspace. No paid stock library, API key or subscription was added.

## Deliverables

| Exercise | Original artwork | Runtime asset | Distinct poses |
| --- | --- | --- | --- |
| March in Place | `march-trainer-source.png` | `trainer_march.png` | 4 |

Runtime assets live in `shared/src/commonMain/composeResources/drawable/` and were mechanically resized to 1200 × 1200 using macOS `sips`. Each uses a 2 × 2 layout. Per-asset second-row crop offsets align the visible floor baseline. Original files are preserved here.

The first March in Place generation repeated the same lifted leg. It was rejected and replaced with a strict front-view sequence showing alternating legs. The rejected file is not bundled.

These are stepped illustrative previews, not motion-capture or rigged 3D models. Visual checks and playback tests are not professional movement certification. Review on a phone and obtain movement review before publishing.
